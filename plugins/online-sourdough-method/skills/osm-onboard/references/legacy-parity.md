read in repository workers; blank asset-based owner home instead of template
clone; optional local-first Git; four discoverable entries instead of phase
skills; product-native updates instead of the legacy update runtime. These
preserve the safety invariants while removing mandatory runtime helpers.

bytes recoverable and preserve its meaning and unknown fields. The migration
lead may make only verified path/caller adaptations under setup authority,

skills source; System/Project methods stay local. Optional external

published here.
