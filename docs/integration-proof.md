# Design and content integration: 0.9.0

AIOS includes design, review-design, openpencil-workbench, content and
diffusion-studio alongside its existing 17 skills. The
[design preservation map](design-preservation.md) and
[content preservation map](content-preservation.md) record where each former
ADS/ACS responsibility now lives. No customer collection is bundled.

Core routing uses the current native workspace and relevant owner context.
New owner homes use format 2 without mandatory repository registers; format 1
remains supported. Existing source indexes are ordinary optional context.
Project material lives in `design/` and `content/` only when needed.

APT's actual generator produces local requirements, proof and recovery notes,
one AGENTS instruction source and a Claude import. Its clean-source identity,
atomic transfer and no-overwrite behavior remain intact. AST removes the former
three-type architecture and retains optional specialist ownership and recovery.
Power BI stays independently maintained, with no change to its runtime.

## Source and helper proof

Run the core validation, per-skill version rehearsal, context footprint, nested
layout and continuity rehearsals described in [verification](verification.md).
The 22-skill package validation admits domain-local helper files and rejects
installation hooks, misplaced executable files, split skill sources, duplicate
lifecycle methods, lost built-in routes and compulsory owner registries.
Selected-read ceilings are unchanged; byte counts are not runtime token usage.

Domain tests run copied helpers against external synthetic working folders.
They cover their documented operations, preservation and path boundaries.
They do not prove installation or operation of OpenPencil, Diffusion Studio,
Whisper, Windows or a publishing account. Use a selected tool's real acceptance
procedure when a task needs it.

## Native and behavioral evidence

The isolated Pi and Claude package lifecycle checks discover all 22 skills,
preserve unrelated fixture settings/skills and remove only AIOS registration.
Claude also verifies a fixture-only version transition and installed skill
byte equality. These initial runs use the integration candidate; final source
identity and any necessary affected reruns are recorded before delivery.
They make no model calls and establish no cross-harness performance claim.

Final domain helper counts, Gemini results, independent Review and scoped
native behavior observations remain pending while integration is in progress.
