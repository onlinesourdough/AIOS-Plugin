# Clarify and the retired standalone shelves

## Accepted outcome

Clarify is an independently selectable AIOS skill for understanding complex
topics and decisions. It owns explanatory judgment: the reader's question,
mental model, examples, sequence, meaningful distinctions and uncertainty.
Visuals are selected when they improve understanding, with presentation owned
by the available native visualization tools. It is separate from Design and
does not require an HTML file, interview or new project.

The owner selected only Clarify for adoption on 1 October 2026. Global Skills
and Skills Atlas are retained as public archives, and the separate Global Skills
plugin is removed after AIOS adoption. Shape Offer, guardrail code and the Atlas
application are not adopted. AIOS already supplies its own skill index and native
discovery; this does not claim replacement of the Atlas application's graph,
hosting or authentication features.

## Source and adaptation

The prior source is
[Global Skills Clarify at 5adf51d](https://github.com/onlinesourdough/Global-Skills/blob/5adf51dbec00fee21c1e06b1c8d153a72a1624fb/skills/clarify/SKILL.md),
with its MIT license and public
[provenance record](https://github.com/onlinesourdough/Global-Skills/blob/5adf51dbec00fee21c1e06b1c8d153a72a1624fb/docs/source-audit.md).
That record credits the visual-explanation idea from Anthropic's `eli5`;
no upstream payload was copied. AIOS adopts selected current instructions and
the explanation purpose, without importing Global Skills Git history or release
metadata. The archived source's historical release/privacy hold remains intact.

The new native `aios:clarify` entry starts at skill version 1.0.0 in AIOS 0.16.0.
The separate plugin's HTML-only output is intentionally adapted: a short answer,
table, static diagram, native interactive visual or requested standalone artifact
can each be sufficient. Accessibility, accurate examples, evidence boundaries
and proportionate rendering inspection remain.

## Verification and recovery

Package validation checks the 26-skill inventory, shared native source, local
documentation, canonical links, independent skill versions and absence of the
unselected Shape Offer and guardrail payloads. Native decision probes inspect
one complex explanation and one simple answer against the candidate. The native candidate read succeeded and returned a correct two-year interest
comparison (1,200 versus 1,210 from the supplied assumptions), explaining why
the second year differs. The simple browser-tab question stayed one sentence,
without a visual or file. Source checks and these bounded probes do not establish
teaching effectiveness for every reader or untested native visualization rendering.

The prior AIOS v0.15.1 is retained for recovery. Archived repositories preserve
the previous methods and application. Removing the Global Skills plugin does not
remove a guard script previously copied into a consumer project's hook directory.
