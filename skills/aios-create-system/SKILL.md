# Create System

Start with a READY owner contract. Apply the
[creation boundary and registration procedure](../aios/references/creation.md)
before acquiring source: duplicate checks, verified seed identity, the empty
final root and one verified repository writer are required. Continue in the
current task unless [shared execution](../aios/references/lifecycle.md) selects
delegation; only then use [Orchestrate workers](../aios-orchestrate-workers/SKILL.md).
Existing repositories are adopted in place and are never refreshed from a
template.


Require purpose, cohesive reusable responsibilities, ownership, invoke
condition, primary route, natural return and proof boundary; explain why
one-off work, a Skill or Project is insufficient. Read the registered seed URL
from systems/README.md, freeze its freshly resolved default-branch commit and
fetch that object under one temporary non-branch seed ref in the final empty
repository. Verify it equals the frozen commit and inspect its root instructions,
README and declared primary and supporting routes directly from that object.
Follow the frozen seed's current adoption instructions to materialize only its
tracked tree while preserving the new repository's own `.git` and unborn
history. Do not check out its history, merge it or make a seed commit.

Re-read the materialized local instructions before transforming. Replace generic
identity and routing with the concrete System, record exact URL@SHA, operation,
proof, recovery and standalone ownership, and retain support only when justified
by the accepted contract.
AIOS does not prescribe the seed's route names, files, transfer tool or support
layout; if its current interface cannot preserve the accepted boundary, stop
instead of manufacturing one.

The registered source supplies a neutral seed, not another System's
implementation. Never copy AIOS owner truth, a sibling capability, runtime,
ledgers, schemas or examples into the new System to simulate its responsibility.
Implement that responsibility locally only after its contract is ready. There
is no seed runtime dependency or later seed refresh.

Retain temporary seed access and all observed files on failed proof. After
concrete identity, primary route, local evals and provenance pass, remove only
the known temporary remote/ref. Prove history is still unborn with zero refs and
remotes, no generic primary identity, and every support path justified.


After proof, the current owner task finalizes the registry row. A delegated
repository worker returns the proposed row to its caller instead of editing
shared owner data. A blocked registry write preserves the canonical new
repository and retries only registration. Continue its local lifecycle under
the same task or selected worker; creating an owner does not authorize external publication.
