# Establish a specialist

Use this method when the accepted result is a separately maintained specialist
solution. Resolve its purpose, users, supported tools/platforms, ownership,
quality and maintenance needs. A reusable skill or ordinary project is often
sufficient; a repository or long process does not require a System framework.
Native skill/plugin creation belongs to [Manage Skills](../aios-manage-skills/SKILL.md).

For a new independent repository, follow [creation](../aios/references/creation.md).
The optional neutral guidance is
https://github.com/onlinesourdough/Agentic-System-Template.git.
Verify its live revision and adoption instructions. Adopt only useful local
requirements with historical source provenance; preserve the destination's
identity and work. There is no later template refresh or runtime dependency.

Implement the specialist using ordinary skills, scripts and tools, with local
requirements and shared [Spec](../aios-spec-work/SKILL.md),
[Build](../aios-build-work/SKILL.md) and [Review](../aios-review-work/SKILL.md).
Add state, validation and recovery only for the actual responsibility. Do not
manufacture a ledger, engine or registry to satisfy the System label.

Finish with the usable entrypoint, dependencies, evidence and maintained source.
Installation and distribution use the chosen harness's native mechanisms under
existing authority; they are separate from creating source files.
