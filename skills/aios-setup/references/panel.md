# Codex context panel

The panel shows Notion connection status and the saved personal context link.
A user can save a link directly with Continue, open it, or change it. It never
sends a message, searches Notion, discovers sources or starts this skill.

Saving a user-supplied link is a bridge-only action, not source verification or
approval of that page's contents. Before using it, Context reads the entry and
reports missing access, guidance or required sources. A Connected badge proves
only the official plugin's observed installation, enablement and connection.

AIOS and Notion remain separate plugins. Use native installation and connection
controls; never duplicate Notion's server, app binding or credentials.

Setup still owns a requested business onboarding: verify the selected entry,
reuse useful Docs, Personal/Team Skills and Memory, preserve Spaces and access,
and prove a first useful task. That work is explicit, never triggered by an
ordinary panel click. Client and plan-only work belongs in that scoped request;
the panel's clearly labelled personal default is not a client setup selector.
