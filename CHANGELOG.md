# Change history

## 0.2.0 — AIOS

Product identity becomes AIOS (`aios@online-sourdough`), with a shared package at
`plugins/aios/`. Eleven useful workforms are directly discoverable. Legacy behavior is retained
in phase-owned checks and conditional references where a separate skill would
add overlap.
Conditional Review checks use client principles, voice sources and actual
visual renders. The README and architecture explain the client installation
and natural setup journey.

New homes use `~/.AIOS`, AIOS.md and AIOS_FORMAT. Format 1 remains unchanged in
meaning; adoption from OSM 0.1.4 or template AIOS uses an explicit identity,
content and registration map with conflict, replay and rollback checks.
A package update does not perform a physical home move or native cutover.
Adaptive onboarding and the existing permission/capability boundaries remain.
Release availability is established by the matching reviewed tag/release, not
by this source entry. See [proof](docs/proof.md).
